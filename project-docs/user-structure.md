## 移动端原型的使用方式

原型底部有五个主要入口：今日、订场、球局、球队、我的。电脑显示手机宽度界面和左侧演示说明；手机显示完整应用界面。通过角色切换进入球童端，查看预约后面的服务过程。

以下是原型的目标演示路径，具体测试结果记录在操作日志中。

### 1. 演示预约一场球

进入「订场」→ 搜索或筛选球场 → 打开球场详情 → 选日期、时段、人数 → 查看费用 → 确认演示预约 → 打开订单详情。随后演示改期或取消，并返回「我的」检查订单状态。

### 2. 演示 18 洞记分与复盘

进入「球局」→ 选择 Tee 与同行 → 开始球局 → 逐洞调整杆数并保存 → 查看 18 洞成绩和总杆 → 完成球局 → 查看 AI 复盘。

弱网开关用于展示断网时的记分体验；保存、刷新和恢复弱网状态后，应能继续查看原有成绩。复盘展示当前记分的统计与练习建议，属于规则生成的模拟内容。

### 3. 演示球队活动与教学

进入「球队」→ 打开约球活动 → 报名 → 回到活动列表查看报名状态 → 演示退出。再打开邀请和教学内容，说明社交与训练入口。

### 4. 演示球童服务

切换为「球童端」→ 查看任务 → 清点装备 → 确认取还 → 提交服务异常记录 → 完成服务 → 查看完成状态。切回球友端查看相应服务提示。

### 5. 演示个人记录与重置

进入「我的」查看订单、历史球局、球包、提醒和收藏。演示完成后可从说明或设置入口重置当前访客的演示数据，再开始下一轮演示。

## 项目文件结构

| 路径 | 用途 |
| --- | --- |
| `project-docs/` | 产品目标、功能范围、技术方案、演示说明、进度与问题记录 |

## 状态与数据流

用户点击或填写内容 → 原型校验 → 服务接口验证 → 数据库保存与回读。弱网先缓存浏览器，恢复后同步；记录可在运营后台查看。当前数据库为MySQL，迁移与联动验收已通过。不连接真实支付、真实球场业务后台、通知或AI服务。
