# 2026-10-13 正式账户与业务切换

正式服务默认不初始化样例数据、不创建匿名工作区。旧测试夹具仅由隔离测试显式传入 `test_fixtures=True` 启用，生产启动入口不提供该开关。

## 登录与保存

- 所有用户业务接口要求有效账号会话。访问首页未登录时跳转 `/login.html`；PC/H5 顶部及个人中心均有退出按钮。
- 退出撤销服务器会话；用户修改密码或后台重置密码撤销其所有会话。停用账号后请求立即被拒绝。
- 未登录、失效会话或网络故障不会回退到匿名访客或本地样例。前端只读取服务器账户数据；保存失败恢复最后确认的状态，不提示成功。
- 前端不允许切换账号角色、到场自核验、伪造球包交接或关闭服务工单。到场与交接由后台工作人员登记。

## 业务资料

上线前已做数据库备份，并把旧示例资料存入私密归档 `data/archives/pre-production-1791850720.json`。归档包括 39 条旧订单、51 条球局、3 个球场、270 个时段、6 个课程、19 个匿名工作区等。迁移检查了实际账号没有业务记录以及目录资料来源均为 seed 后才清理；保留实际登录账号、密码哈希、管理员账号、AI 配置和 APK。审计日志保留历史事实。

球场、时段、教学和活动由后台录入并发布。没有记录时显示空状态，不再补入默认球场、天气、距离、成绩、人物和消息。新活动按开放日期选取，不依赖固定样例编号。AI 已审核帮助资料对应 `/help.html`；缺少实际 Par 时不输出虚构相对标准杆统计。

目前预约为本站库存与后台管理流程；不提供第三方球场系统、线上收退款或推送通知。界面不提供模拟支付、模拟推送或虚假成功反馈。球局为个人 18 洞记分，团队多人同步与 PK 结算不作为已上线能力展示。
